# 视频生成流程标准

> 所有图文转视频（含抖音自动转视频）必须遵循本标准。代码入口：`web/app.py` → `_generate_publish_video`。

---

## 1. 输入

| 参数 | 来源 | 说明 |
|------|------|------|
| `title` | 发布中心标题 | 用于 BGM 风格匹配 |
| `body` | 发布中心正文 | 用于 LLM 改写口播稿 |
| `media` | 发布中心图片列表 | 仅图片，不传旧视频（避免复用静音缓存） |
| `native_platforms` | 平台选择 | 抖音在只有图片时自动触发图文转视频 |
| `voice` | 页面音色配置 | 系统音色或克隆音色；空时读取 `/api/voices` 当前默认值，禁止使用脚本内置音色 |
| `bgm` | BGM 曲库 | 用户选择的曲库相对路径；空时从公共曲库自动匹配 |
| `digital_human` | 数字人管理 | 数字人角色 ID；生成时解析为持久化角色照片，禁止临时生成人像 |
| `digital_human_pos` | 发布中心数字人位置 | `bottom-right`（默认）/ `bottom-left` / `top-right` / `top-left` |
| `generation_confirmed` | 制作确认弹窗 | 必须为 true 才能进入媒体生成；否则后端硬拒绝 |
| `force_regenerate` | 重新生成操作 | true 时跳过缓存，但仍需制作配置确认 |

**约束**：
- 不允许传入旧视频绕过重新生成（发布时只选图片）
- 图片数量 = 视频分镜数（每张图一个镜头）

---

## 2. 流程（8 步，顺序执行）

```
用户需求 + 图片素材
  ↓
⓪ 制作配置预检：页面默认 TTS + 数字人角色 + BGM 曲库 + 付费调用清单
  ↓ 等待用户确认，并写 generation_manifest.json
① LLM 改写口播稿（N 段，N=图片数）
  ↓
② 逐段 TTS 合成（百炼 CosyVoice + 逐句 SRT，音色由用户选择）
  ↓
③ 拼接完整口播音频（ffmpeg concat）
  ↓
④ 合并逐句字幕（时间戳偏移累加）
  ↓
⑤ BGM 自动选曲（风格匹配 + 降级）
  ↓
⑥ assemble.py 合成（每镜时长=口播时长，字幕烧录，BGM混音）
  ↓
⑦ 数字人 overlay（可选：百炼 EMO 生成 → FFmpeg overlay 到右下角）
  ↓
最终 MP4（1080×1920 竖版）
```

### ⓪ 制作配置预检

- TTS：读取 `/api/voices` 的 `engine`、`default` 和音色状态。
- 数字人：读取 `/api/digital-human/characters`，请求明确包含数字人且只有一个角色时默认选该角色；多个角色时等待用户选择。
- BGM：读取 `/api/bgm`，默认复用曲库；除非用户明确要求并确认费用，不调用音乐生成模型。
- 付费清单：展示 provider、model、最大调用次数和费用范围。
- 用户确认后写 `assets/generation_manifest.json`；未确认不得进入后续步骤。
- “重新生成”不等于授权复用历史 TTS、avatar、BGM 或付费素材。

### ① LLM 改写口播稿

| 项 | 规格 |
|----|------|
| 模型 | `qwen-plus`（dashscope 兼容 OpenAI 格式） |
| 段数 | = 图片数量 |
| 每段要求 | 2-4 个短句，每句 ≤ 12 字（含标点），口语化有节奏 |
| 第 1 段 | 必须有钩子（抓人眼球） |
| 最后一段 | 必须有互动引导 |
| 输出格式 | JSON 数组，N 个字符串 |
| 降级 | LLM 不可用时按句切分正文（`_split_captions`） |

**Prompt 要点**：
- 每句 ≤ 12 字（字幕单行显示需要）
- 口语化、有节奏感、像真人说话
- 保留原文核心观点但重新组织语言

### ② 逐段 TTS 合成

| 项 | 规格 |
|----|------|
| 引擎 | 页面当前配置的百炼 CosyVoice 或 Qwen-TTS |
| 音色 | `/api/voices` 返回的默认音色，或用户本轮确认的音色 ID |
| 调用 | `tts.py speak --file <文本> -o <音频> --engine closed --voice <voice_id> --subtitle <SRT>` |
| 逐句 SRT | tts.py 闭源路径按句号切分，每句一条字幕，时间戳=该句真实时长 |
| 超时 | 单段 120s |
| 失败 | 立即停止并保留原始错误；禁止降级到 edge-tts、禁止自动换音色 |

**系统音色列表**（免费，直接可用）：

| voice_id | 名称 | 描述 | 适合场景 |
|----------|------|------|----------|
| `longxiaochun_v2` | 龙小淳 | 知性积极女声 | 口播/讲解 |
| `longcheng_v2` | 龙橙 | 阳光男声 | 新闻/播报 |
| `longhua_v2` | 龙华 | 活泼女声 | 种草/电商 |
| `longwan_v2` | 龙婉 | 柔声女声 | 情感叙事 |
| `longshu_v2` | 龙书 | 沉稳男声 | 商业/科技 |
| `longyue_v2` | 龙悦 | 甜美女声 | 生活方式 |
| `longji_v2` | 龙吉 | 少年男声 | 年轻向 |

**声音克隆**（百炼 CosyVoice zero-shot，免费创建）：

- 用户上传 10-20 秒清晰人声音频 → 调百炼 `create_voice` → 秒级返回 `voice_id`
- 克隆音色状态 `DEPLOYING → OK` 后即可用于 TTS
- 克隆音色和系统音色统一在发布中心音色选择器展示
- API：`POST /api/voices/clone`（上传音频）、`GET /api/voices/clone/status/<id>`（轮询状态）
- 每账号最多 1000 个克隆音色，1 年未使用自动清理

**音色预览**：

- 每个音色可生成 3 秒试听音频（`GET /api/voices/preview/<voice_id>`）
- 首次请求时懒生成并缓存到 `outputs/_shared/voices/preview/`

### ③ 拼接完整口播音频

```bash
ffmpeg -y -f concat -safe 0 -i <list.txt> -c:a libmp3lame -b:a 128k <narration_full.mp3>
```

- 用 ffmpeg concat 拼接所有段音频
- 输出 128k MP3

### ④ 合并逐句字幕

- 合并所有段的 SRT 为一个完整 SRT
- 时间戳按各段时长偏移累加（`_merge_srt_files`）
- 字幕内容 = 口播逐句文本，跟随口播时间戳
- **不使用** `_auto_srt`（整段 caption 生成字幕）

### ⑤ BGM 自动选曲

| 项 | 规格 |
|----|------|
| 选曲逻辑 | `_video_bgm(title, body)` 按内容风格匹配 |
| 风格降级 | tech 无曲目 → corporate → 其他可用风格 |
| 音量 | `bgm_volume: 0.35`（明显但不盖口播） |
| 曲库 | `outputs/_shared/bgm/`，元数据 `_meta.json` |
| 降级 | 无匹配 → 静音（消息明确说明） |

### ⑥ assemble.py 合成

| 项 | 规格 |
|----|------|
| 脚本 | `skills/openclaw/auto-short-video/scripts/assemble.py` |
| 画幅 | 1080×1920（竖版） |
| 每镜时长 | = 对应段口播真实时长（音画同步） |
| 字幕 | 优先用 `storyboard.subtitle`（TTS 逐句 SRT），不用 caption |
| 字体 | `_resolve_sub_font()` 自动回退（Noto Sans CJK SC → Heiti SC → ...） |
| 字号 | `min(w,h) * 0.05`（竖版 54px） |
| 字幕位置 | 底部居中，MarginV = h * 0.07 |
| 字幕样式 | 白字黑描边（Outline=2），单行为佳 |
| BGM | 循环裁剪压低后混音 |
| 超时 | 900s |

**Storyboard 结构**：
```json
{
  "size": "1080x1920",
  "image_motion": "static",
  "shots": [
    {"image": "card_1.png", "duration": 2.86, "motion": "static"},
    {"image": "card_2.png", "duration": 3.50, "motion": "static"}
  ],
  "narration": "narration_full.mp3",
  "subtitle": "narration_full.srt",
  "bgm": "Deliberate Thought.mp3",
  "bgm_volume": 0.35
}
```

**注意**：shots 不设 `caption`，字幕统一由 `subtitle`（SRT）提供。

### ⑦ 数字人 overlay（可选）

| 项 | 规格 |
|----|------|
| 触发条件 | 用户确认了数字人管理中的角色 ID |
| API | 百炼 悦动人像 EMO（`emo-v1`） |
| 输入 | 角色持久化照片 + 本轮实际口播音频 |
| 流程 | 上传到百炼 → EMO 图像检测 → 创建异步任务 → 轮询状态 → 下载视频 |
| 输出尺寸 | 512×512（1:1）或 512×704（3:4），由 EMO 自动决定 |
| overlay | FFmpeg 等比缩放至 200px 宽，叠加到主视频指定位置 |
| 位置 | `bottom-right`（默认）/ `bottom-left` / `top-right` / `top-left` |
| 超时 | 10 分钟（轮询 40 次 × 15 秒） |
| 费用 | 0.08 元/秒（1:1 画幅），1800 秒免费额度 |
| 失败 | 请求要求数字人时停止交付并保留主片；禁止用 AI 生图 + 普通 I2V 或历史 avatar 冒充 |

**FFmpeg overlay 命令**：
```bash
ffmpeg -y -i main.mp4 -i dh.mp4 \
  -filter_complex "[1:v]scale=200:-2[dh];[0:v][dh]overlay=W-w-30:H-h-30" \
  -c:a copy -c:v libx264 -preset fast output.mp4
```

## 3. 输出

| 项 | 规格 |
|----|------|
| 文件 | `outputs/_generated_videos/<fingerprint>.mp4` |
| 指纹 | 标题、正文、图片路径/大小/修改时间、TTS 引擎、音色 ID、BGM 路径、数字人角色 ID/位置的稳定哈希 |
| 缓存 | 仅完整配置指纹一致、manifest 状态为 completed 且成片自检通过时复用 |
| 清单 | `outputs/_generated_videos/<fingerprint>.manifest.json` |
| 中间产物 | `outputs/_generated_videos/<fingerprint>_assets/`，失败和成功均保留 |
| 画幅 | 1080×1920 竖版 |
| 视频编码 | H.264 |
| 音频编码 | AAC |
| 时长 | = 口播总时长（口播完整播完） |

---

## 4. 质量标准

| 指标 | 合格标准 |
|------|----------|
| 口播 | 页面确认的 CosyVoice/Qwen-TTS 音色，禁止 edge-tts |
| 口播完整性 | 视频时长 ≥ 口播时长（口播不被截断） |
| 数字人 | 角色 ID、持久化照片、本轮口播音频均与 manifest 一致；EMO 失败不交付完整成片 |
| 音画同步 | 每镜时长 = 对应段口播时长 |
| 字幕 | 逐句跟随口播，单行显示，白字黑描边 |
| BGM | 风格匹配，音量 0.35，能听见但不盖口播 |
| 字体 | 系统可用中文字体（不依赖 Noto Sans CJK SC） |
| 结果消息 | 明确说明口播来源、BGM 曲名、降级原因 |

## 5. 抖音发布触发

| 条件 | 行为 |
|------|------|
| 只有图片 + 选抖音 | 自动触发图文转视频（带口播+BGM），生成后用视频发布 |
| 已有视频 + 选抖音 | 直接用视频发布 |
| 只有图片 + 选视频号/B站 | 强制图文转视频（VIDEO_ONLY 平台） |

**Job 执行**：
- media task 在独立线程并行生成视频
- 抖音 task 等待 media task 完成后再发布（`media_thread.join()`）
- 生成失败 → 抖音 task 标记失败，不发图文
- 生成成功 → 用视频发布（`run_task(task, req)`，req.media 已追加视频路径）

## 6. 降级策略

| 环节 | 降级条件 | 降级行为 | 消息说明 |
|------|----------|----------|----------|
| LLM 改写 | dashscope 不可用 | 按句切分正文 | "按句切分（LLM 不可用）" |
| TTS 口播 | 页面默认音色/闭源引擎失败 | 停止，修复配置后重试 | 原始 provider 错误 |
| BGM 选曲 | 风格无曲目 | 从曲库列出其他候选，等待选择 | "无同风格曲目" |
| BGM 生成 | 用户未明确要求或未确认费用 | 禁止调用音乐模型 | 不产生调用 |
| BGM 选曲 | 无可用曲目 | 静音 | "静音" |
| 字体 | Noto 缺失 | Heiti SC / Hiragino / sans-serif | 自动回退 |

**原则**：降级不能静默跳过，必须在结果消息中明确说明原因。

## 7. 完整流程时序图

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant UI as Easel 对话/发布页面
    participant R as OpenClaw 路由层
    participant OPT as 配置 API
    participant M as generation_manifest
    participant C as 成片缓存
    participant LLM as 口播脚本模型
    participant TTS as CosyVoice/Qwen-TTS
    participant SUB as 字幕处理
    participant LIB as BGM 曲库
    participant ASM as assemble.py
    participant EMO as 百炼 EMO 数字人
    participant V as ffprobe 自检
    participant P as 成片交付/发布任务

    U->>UI: 提出需求 + 上传/选择图片<br/>指定口播、字幕、BGM、数字人、画幅等
    UI->>R: 发送完整制作请求
    R->>R: 识别为完整口播视频
    Note over R: 必须路由 auto-short-video<br/>禁止 ai-video-gen / ai-image-gen 冒充数字人

    par 查询页面默认音色
        R->>OPT: GET /api/voices
        OPT-->>R: engine + default + voices/status
    and 查询数字人角色
        R->>OPT: GET /api/digital-human/characters
        OPT-->>R: 角色 ID + 名称 + 持久化照片
    and 查询 BGM 曲库
        R->>OPT: GET /api/bgm
        OPT-->>R: 曲目路径 + 风格 + 试听地址
    end

    R->>UI: 展示制作确认表<br/>画幅、TTS、数字人、BGM、付费模型/次数/费用
    UI->>U: 显示默认值和全部可修改项

    alt 用户修改配置
        U->>UI: 修改音色/角色/BGM/位置/画幅
        UI->>R: 返回修改后的选择
        R->>UI: 复述最终配置和付费上限
        U->>UI: 确认
    else 用户接受默认值
        U->>UI: 确认
    end

    alt 用户未确认
        R-->>UI: 停止，不调用 TTS/EMO/生图/I2V/音乐模型
    else 用户已确认
        R->>M: 写入 manifest(status=running)<br/>记录配置、provider/model、max_calls
        R->>C: 计算完整 fingerprint<br/>正文+图片元数据+TTS+BGM+数字人+位置

        alt 缓存、manifest、自检全部匹配
            C->>V: 校验文件非空、时长、视频轨、音频轨
            V-->>C: 通过
            C-->>R: 复用已验证成片
        else 未命中或要求重新生成
            R->>LLM: 按图片数量生成对应口播段落
            alt LLM 不可用
                LLM-->>R: 失败
                R->>R: 确定性按句切分正文
            else LLM 成功
                LLM-->>R: N 段口播稿
            end

            loop 每张图片对应一段
                R->>TTS: 已确认 engine + voice_id + 文本
                alt TTS 成功
                    TTS-->>R: 分段音频
                    R->>SUB: 生成/接收该段 SRT
                    SUB-->>R: 分句时间轴
                else TTS 失败
                    TTS-->>R: 原始 provider 错误
                    R->>M: status=failed + 错误
                    R-->>UI: 停止；禁止降级 edge-tts 或换音色
                end
            end

            R->>R: FFmpeg concat 拼接完整口播
            R->>SUB: 合并所有 SRT 并累加时间偏移
            SUB-->>R: narration_full.srt

            R->>LIB: 读取用户确认曲目<br/>或按内容从曲库稳定匹配
            alt 曲库有可用 BGM
                LIB-->>R: 本地 BGM 路径
            else 曲库无可用 BGM
                LIB-->>R: 无可用曲目
                R-->>UI: 列出缺口；不自动调用 fun-music
            end

            R->>ASM: storyboard + 图片 + 口播 + SRT + BGM
            ASM-->>R: base.mp4

            alt 用户确认使用数字人
                R->>OPT: 用 character_id 解析持久化照片
                OPT-->>R: 角色照片
                R->>EMO: 角色照片 + 本轮 narration_full.mp3
                alt EMO 成功
                    EMO-->>R: 数字人口播视频
                    R->>R: overlay 到 base.mp4 指定位置
                else EMO 失败或超时
                    EMO-->>R: 原始任务错误
                    R->>M: status=failed + 错误
                    R-->>UI: 停止完整成片交付<br/>禁止 AI 生图 + 普通 I2V 替代
                end
            end

            R->>V: ffprobe 最终自检
            V->>V: 文件非空、时长>0、视频轨、音频轨<br/>字幕/口播/BGM/数字人配置与 manifest 一致
            alt 自检失败
                V-->>R: 失败原因
                R->>M: status=failed
                R-->>UI: 保留中间产物，停止交付
            else 自检通过
                V-->>R: verified
                R->>M: status=completed + output + assets_dir
                R->>C: 保存最终 MP4 和完整配置缓存
            end
        end

        R->>P: 返回成片、manifest、实际 TTS/BGM/数字人说明
        P->>UI: 展示视频供用户验收
        UI->>U: 播放最终视频

        alt 用户要求调整
            U->>UI: 指定修改项
            UI->>R: 回到配置确认<br/>新 fingerprint，不误用旧缓存
        else 用户确认发布
            U->>UI: 确认发布平台
            UI->>P: 创建发布 Job
            P-->>UI: 发布状态/结果
        end
    end
```

### 时序硬门摘要

1. 完整视频只能路由到 `auto-short-video`。
2. 用户确认前只允许读取三个配置 API，不允许付费生成。
3. TTS 必须使用页面确认的闭源音色；失败不降级。
4. BGM 默认来自曲库；不自动调用 `fun-music`。
5. 数字人必须是角色照片 + 本轮实际口播音频 → EMO。
6. 缓存必须同时匹配完整 fingerprint、completed manifest 和成片自检。
7. 任一必选环节失败，保留中间产物并停止交付，不以降级片冒充完整成片。
