# 风格设定

## 语气基调
热情、节奏快、促单感强、有感染力。像一个兴奋的朋友在告诉你"这个真的太好用了，赶紧买！"语速偏快，情绪饱满，但不虚假做作。让观众感受到"真的为你好"。

## 开头结构
- **痛点引入**：「还在为XX发愁？今天这款直接帮你解决……」
- **价格对比**：「专柜卖399，今天直播间只要……」
- **限时福利开场**：「家人们注意，这个福利只有今天……」

## 视觉风格
- 高饱和色彩，视觉冲击力强
- 商品特写镜头，细节展示到位
- 价格信息醒目(大字、红色、跳动效果)
- 画面节奏快，3-5秒一个切换

## 内容节奏
- 短平快(15-60s)为主，符合碎片化浏览
- 单品推荐30-60秒讲透核心卖点
- 开箱测评可适当延长至1-3min
- 促销类内容突出紧迫感

## 标志性元素
- "321上链接"上链话术
- 限时倒计时动画
- 价格对比图(原价vs直播价)
- 商品编号展示(方便粉丝下单)
- 固定开场白(如"家人们好，今天又给你们带了几个好东西")
- 背景统一货架/直播场景
